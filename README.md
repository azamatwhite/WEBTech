# WEBTech Restaurant Website

A simple static website for a restaurant, featuring menus, booking, gallery, and delivery information.

## Project Structure

The project consists of HTML files for different pages of the website:
- `index.html` - Homepage
- `menu.html` - Restaurant menu 
- `booking.html` - Table reservation
- `delivery.html` - Delivery information
- `gallery.html` - Photo gallery
- `about.html` - About us
- `feedback.html` - Customer feedback
- `careers.html` - To start career with us

## Getting Started

Since this is a static website, you can simply open `index.html` in your web browser to view the site. No build process or server is strictly required, though a local development server can be used for a better development experience.
