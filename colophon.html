How We Built This Site

Project Overview

This project was developed for our Web Technologies Assignment 1 at Astana IT University. We were tasked with building a fully functional, multi-page website using pure HTML5 without any CSS, JavaScript, or front-end frameworks. The goal was to prove our foundational understanding of semantic web structure and to create a site that degrades gracefully when styles are entirely absent.

We chose to build a website for Saya Sushi, a popular local restaurant chain. Documenting a real business allowed us to practice gathering real-world assets, such as menus, pricing, and photography, rather than relying on placeholder text like Lorem Ipsum or stock imagery.

The site represents Say Saya — Eat Sushi! — the official slogan of Saya Sushi, a local restaurant chain in Astana.
